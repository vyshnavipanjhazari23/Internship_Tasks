# Python Task 07 – HackerRank Coding Practice

This folder contains Python solutions for all 20 Task 07 HackerRank problems.

## Files
- `problem1.py` through `problem20.py` correspond to questions 1–20 in the task sheet.
- Each file includes the problem name and HackerRank link at the top.

## How to run
Open a terminal in this folder and run a file, for example:

```bash
python problem1.py
```

Each solution expects input in the format specified by its HackerRank problem.
